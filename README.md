# Customer Churn Analysis

## Project Overview

Customer churn is one of the biggest challenges for subscription-based businesses. This project analyzes customer data to identify the major factors contributing to customer churn and provides business insights that can help improve customer retention.

The project combines **SQL**, **Python**, and **Power BI** to perform data cleaning, exploratory data analysis, statistical testing, and interactive dashboard visualization.

---

## Objectives

- Analyze customer churn behavior.
- Identify key factors influencing customer attrition.
- Perform data cleaning and preprocessing.
- Conduct Exploratory Data Analysis (EDA).
- Validate relationships using statistical testing.
- Build an interactive Power BI dashboard for business insights.

---

## Dataset

**Dataset:** Telco Customer Churn Dataset

The dataset contains customer information including:

- Customer ID
- Gender
- Senior Citizen
- Partner
- Dependents
- Tenure
- Phone Service
- Internet Service
- Contract Type
- Payment Method
- Monthly Charges
- Total Charges

## Key Insights

- Customers on month-to-month contracts are more likely to churn.
- Higher monthly charges are associated with increased churn.
- Customers with longer tenure tend to remain loyal.
- Certain payment methods show higher churn rates.
- Contract type is one of the strongest indicators of customer retention.
